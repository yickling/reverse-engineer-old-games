# Instructions for agents

Read [LLMs.md](LLMs.md) before studying a game, then that game's `README.md`. Write the notes in the shape in [note-shape.md](note-shape.md).

Write every finding into those files before you finish. A chat reply is not a record. The next session will not see it. An address, file, or field you saw and did not read goes in the game's `README.md`, under that topic's heading.

The chat may summarize what was written. Do not end with the result only in the chat.
