# Prompt

Paste the block below to start or continue a study. Fill the brackets. One session does one task. The order is [procedure.md](procedure.md).

```
Read LLMs.md, procedure.md, and note-shape.md. Then read <game>/README.md if that folder exists.

Game folder: <game>
Task: <Start the study at the first open phase. | Do the open item "<title>" and nothing else.>

The program is the local copy. Read it. Leave it unchanged. A note cites an offset from a base the file records, or a file offset in the program as shipped. The note does not name the local copy.

The study is the play this program has. Read each body the way LLMs.md describes for this container. The reader's output is not original source. Do not run the game. A phase this program has no system for is one sentence in the index, and the session goes on. Write each finding into the topic file before you finish. When the finding is something the player sees, say what they see in that same place. A chat reply is not a record. An address, file, or field you saw and did not read goes in <game>/gaps.md under that topic. Remove the row when the finding is written. Do not paste scenario prose. A file the archives do not hold stays absent.

Follow procedure.md. Stop when this task's done line is met.
```
