Character id, portrait, map sprite

The number on each card is the character id. It is the portrait index, the map-sprite index, and the number in the STAND, ACT, and MAGIC filenames. The small picture is map frame 0 (facing 0, step 0) at three times the 24×24 cell. Ids 0–59 are Friaprda rows. Ids 60–150 are EnemyDat rows of id − 60. Ids 151–159 have pictures and no stat row. Class is the class byte stored with that row. A blank card has a picture slot whose pixels are all transparent.
