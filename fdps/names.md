# Names

Part of the [FDPS notes](README.md). Decompiled functions are Ghidra output, not original source. Nothing here was checked by running the game.

These are the strings the program draws. A cell can be off by one stroke, in [Text](text.md). What each spell and item does is in [Combat](combat.md).

## Characters

A character is interface string `id + 1` of `FDETXT00.TXT`. The status sheet and the roster draw that string from byte `+8`. Ids with an empty string are left out. Ids 15–34, 36–58, and 129–149 are empty. Ids 0 through 14 and 35 and 59 through 128 are named. Ids from 60 are the enemies and the other portraits. The first fifteen are the roster names.
